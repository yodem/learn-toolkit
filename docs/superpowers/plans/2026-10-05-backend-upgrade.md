# Backend upgrade (Exa + Tavily, keys in plugin config, weekly drift check) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring learn-toolkit's Exa and Tavily wiring to the October 2026 state of both products, move both API keys into sensitive plugin `userConfig`, add an opt-in `--deep` research path through Exa Agent, and keep it current with a weekly dev-server drift check that opens a PR and pings Telegram.

**Architecture:** `.mcp.json` declares three remote `http` servers (`tavily`, `exa`, `exa-agent`) whose auth headers are filled from `${user_config.*}`; the skill finds tools by name suffix, never by hard-coded `mcp__exa__` prefix. A stdlib-only `scripts/check-backends.py` compares the plugin with the live MCP tool lists, Exa's own tool registry and published package versions, and a cron wrapper on the dev server turns a non-zero exit into a draft PR plus a Telegram message.

**Tech Stack:** Claude Code plugin manifest + `.mcp.json`, Markdown skill, bash lint, Python 3 stdlib (`urllib`, `unittest`), cron, `gh`, `claude -p`, Node (herdr Telegram plugin lib).

**Spec:** `.team/runs/2026-10-05-backends/goal.md` (criteria), `explore.md` (live probe results), `research.md` (exact API facts with sources).

## Global Constraints

- MCP server `type` is `"http"` for every remote server (`"url"` is rejected: `claude mcp list` prints `Skipped — unknown MCP server type "url"`).
- Keys only via `${user_config.exa_api_key}` / `${user_config.tavily_api_key}`; both declared `"sensitive": true, "required": false` in `plugin.json`. No `${EXA_API_KEY}` / `${TAVILY_API_KEY}` and no `apiKey=` query parameter anywhere in `.mcp.json`.
- Exa header is `x-api-key`; Tavily header is `Authorization: Bearer …`. Exa `tools=` for `exa`: `web_search_exa,web_fetch_exa,web_search_advanced_exa`; for `exa-agent`: `agent_run` (a keyless `agent_run` listing 401s the whole connection, so it lives on its own server).
- Deprecated, never used: `get_code_context_exa`, `company_research_exa`, `people_search_exa`, `linkedin_search_exa`, `deep_search_exa`, `crawling_exa`, `deep_researcher_start`, `deep_researcher_check`; Exa categories `github`, `pdf`, `tweet`, `linkedin`, `research paper`.
- Allowed Exa categories: `company`, `publication`, `news`, `personal site`, `people`, `financial report` (`company`/`people` reject date filters and `excludeDomains`).
- Plugin tools are namespaced `mcp__plugin_learn-toolkit_<server>__<tool>`; the skill matches by `__<tool>` suffix.
- Tavily CLI floor `tvly` >= 0.1.8; subagents never run `tvly login` (exit code 3 = auth, report it).
- Exa Agent effort default `medium`; `--deep=high|xhigh` only when the user passes it.
- Version 2.2.0 in `plugin.json`, `.claude-plugin/marketplace.json`, SKILL.md `metadata.version`.
- No secret ever printed, logged, committed or put in a PR body; `check-backends.py` never reads an API key.
- The weekly job pushes only `backend-drift/*` branches, opens draft PRs, never touches `main`.
- Anything written where others read it (PR bodies, commit messages) says `_(Claude, on Yotam's behalf)_`.

## Review Focus

1. A user who leaves both keys blank: `exa` still connects keyless, `exa-agent` fails alone, `tavily` asks for OAuth; `/learn` runs on Exa keyless or the `tvly` CLI, and `--deep` prints one "needs an Exa key" notice instead of failing. Pinned by Task T1 Step 6 (blank-config install test).
2. A user upgrading from 2.1.0 with `EXA_API_KEY`/`TAVILY_API_KEY` exported: those env vars are no longer read; the skill's missing-backend message must say `/plugin configure learn-toolkit@learn-toolkit-marketplace`, never "export". Pinned by T2 lint check `no-env-key-advice`.
3. Tool namespacing: a user with their own user-scope `exa` server *and* the plugin's sees two copies; probes match any `__web_search_advanced_exa` suffix. Pinned by T2 lint check `no-hardcoded-mcp-prefix`.
4. An `agent_run` that outlives one MCP call returns `status: "running"` + `id`: the skill re-calls with `runId`, never reads output before `completed`, and treats `failed`/`cancelled` as a degraded run. Pinned in T1 SKILL.md Phase 1b text and T2 lint check `agent-run-polling`.
5. The weekly job when the network or GitHub is down: exit 3, Telegram "check could not run", no branch, no PR; a second run on the same day reuses/suffixes the branch name. Pinned by T2 unit test `test_probe_error_exit3` and T3 Step 4 dry run with `CHECK_FORCE_EXIT=3`.

`tests/test_check_backends.py` (stdlib `unittest`, imports the script with `importlib`; network replaced by an injected `fetch(url, headers) -> (status, text)`):

```python
import importlib.util, json, pathlib, unittest
ROOT = pathlib.Path(__file__).resolve().parents[1]
spec = importlib.util.spec_from_file_location("cb", ROOT / "scripts" / "check-backends.py")
cb = importlib.util.module_from_spec(spec); spec.loader.exec_module(cb)
REG = (ROOT / "tests" / "fixtures" / "toolRegistry.ts").read_text()

class Registry(unittest.TestCase):
    def test_parses_deprecated_and_current(self):
        cur, dep = cb.parse_exa_registry(REG)
        self.assertIn("web_search_exa", cur); self.assertIn("agent_run", cur)
        self.assertIn("get_code_context_exa", dep); self.assertNotIn("web_fetch_exa", dep)

class Plugin(unittest.TestCase):
    def test_used_exa_tools_from_mcp_json(self):
        used = cb.used_exa_tools(ROOT / ".mcp.json")
        self.assertEqual(used, {"web_search_exa", "web_fetch_exa", "web_search_advanced_exa", "agent_run"})

class Compare(unittest.TestCase):
    def test_deprecated_use_is_breaking(self):
        f = cb.compare_exa({"get_code_context_exa"}, {"web_search_exa"}, {"get_code_context_exa"})
        self.assertEqual(f[0]["severity"], "breaking")
    def test_new_upstream_tool_is_info(self):
        f = cb.compare_exa({"web_search_exa"}, {"web_search_exa", "brand_new_exa"}, set())
        self.assertEqual([x["severity"] for x in f], ["info"])
    def test_version_change_is_info(self):
        f = cb.compare_versions({"tavily-cli": "0.1.8"}, {"tavily-cli": "0.1.9"})
        self.assertEqual(f[0]["severity"], "info")

class ExitCodes(unittest.TestCase):
    def test_probe_error_exit3(self):
        def down(url, headers=None): raise OSError("network down")
        report = cb.run(fetch=down, offline=False)
        self.assertEqual(cb.exit_code(report), 3)
    def test_clean_offline_exit0(self):
        report = cb.run(fetch=None, offline=True)
        self.assertEqual(cb.exit_code(report), 0, json.dumps(report, indent=1))

class NoSecrets(unittest.TestCase):
    def test_script_never_reads_api_keys(self):
        src = (ROOT / "scripts" / "check-backends.py").read_text()
```

```python
Exit: 0 clean, 1 breaking drift, 2 informational drift, 3 probe error."""

    "tavily-python": ("https://pypi.org/pypi/tavily-python/json", ["info", "version"]),
    "exa-py": ("https://pypi.org/pypi/exa-py/json", ["info", "version"]),
    "tavily-mcp": ("https://registry.npmjs.org/tavily-mcp/latest", ["version"]),
    "exa-mcp-server": ("https://registry.npmjs.org/exa-mcp-server/latest", ["version"]),
}
DOC_INDEXES = {"exa": "https://exa.ai/docs/llms.txt", "tavily": "https://docs.tavily.com/llms.txt"}

def http_fetch(url, headers=None, body=None):
    h = {"User-Agent": UA, **(headers or {})}
    req = urllib.request.Request(url, data=body, headers=h, method="POST" if body else "GET")
    try:
        with urllib.request.urlopen(req, timeout=30) as r:
            return r.status, r.read().decode(), dict(r.headers)
    except urllib.error.HTTPError as e:
        return e.code, "", dict(e.headers or {})

def parse_exa_registry(ts):
    """-> (current, deprecated) tool-id sets from TOOL_REGISTRY's `id: { name: "..." }` entries."""
    cur, dep = set(), set()
    for tool, name in re.findall(r'^\s{2}([a-z_]+):\s*\{\s*name:\s*"([^"]+)"', ts, re.M):
        (dep if "deprecated" in name.lower() else cur).add(tool)
    return cur, dep

def used_exa_tools(mcp_json_path):
    data = json.loads(pathlib.Path(mcp_json_path).read_text())
    used = set()
    for s in data["mcpServers"].values():
        if "mcp.exa.ai" in s.get("url", ""):
            used |= {t for t in parse_qs(urlparse(s["url"]).query).get("tools", [""])[0].split(",") if t}
    return used
```
